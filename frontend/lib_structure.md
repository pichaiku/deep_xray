# โครงสร้าง Folder/File ใน /lib

โฟลเดอร์ `lib/` เป็นโฟลเดอร์หลักสำหรับเก็บซอร์สโค้ดของแอปพลิเคชัน Flutter ในโปรเจกต์นี้ โครงสร้างภายในแบ่งออกเป็นโฟลเดอร์ย่อยต่างๆ เพื่อจัดระเบียบโค้ดให้ง่ายต่อการจัดการและพัฒนา

## โครงสร้างโฟลเดอร์

```
lib/
├── main.dart
├── providers/
│   ├── auth_provider.dart
│   └── xray_provider.dart
├── screens/
│   └── home_screen.dart
├── services/
│   └── api_service.dart
├── theme/
│   └── app_theme.dart
└── widgets/
    ├── prediction_results.dart
    └── xray_viewer.dart
```

## คำอธิบายแต่ละส่วน

### main.dart
- **ตำแหน่ง**: `lib/main.dart`
- **คำอธิบาย**: ไฟล์หลักที่เป็นจุดเริ่มต้นของแอปพลิเคชัน Flutter ประกอบด้วยฟังก์ชัน `main()` และการตั้งค่าเริ่มต้นของแอป รวมถึงการเรียกใช้ `runApp()` เพื่อเริ่มแอป

### providers/
- **ตำแหน่ง**: `lib/providers/`
- **คำอธิบาย**: โฟลเดอร์สำหรับเก็บคลาส Provider ที่ใช้ในการจัดการสถานะ (State Management) ของแอป โดยใช้แพทเทิร์น Provider จาก Flutter
  - **auth_provider.dart**: จัดการสถานะที่เกี่ยวข้องกับการยืนยันตัวตน (Authentication) เช่น การล็อกอิน ล็อกเอาท์ และการจัดการโทเค็น
  - **xray_provider.dart**: จัดการสถานะที่เกี่ยวข้องกับฟังก์ชัน X-ray เช่น การจัดการข้อมูลภาพ X-ray และผลการวิเคราะห์

### screens/
- **ตำแหน่ง**: `lib/screens/`
- **คำอธิบาย**: โฟลเดอร์สำหรับเก็บหน้าจอ (Screens) หรือหน้า UI ต่างๆ ของแอป
  - **home_screen.dart**: หน้าจอหลักของแอป ที่แสดงเมนูหลักหรือแดชบอร์ดสำหรับผู้ใช้

### services/
- **ตำแหน่ง**: `lib/services/`
- **คำอธิบาย**: โฟลเดอร์สำหรับเก็บคลาสที่จัดการลอจิกทางธุรกิจหรือการสื่อสารกับเซิร์ฟเวอร์ภายนอก
  - **api_service.dart**: จัดการการเรียก API ต่างๆ รวมถึงการส่งข้อมูลไปยังเซิร์ฟเวอร์และรับข้อมูลกลับมา

### theme/
- **ตำแหน่ง**: `lib/theme/`
- **คำอธิบาย**: โฟลเดอร์สำหรับเก็บการตั้งค่าธีม (Theme) ของแอป
  - **app_theme.dart**: กำหนดธีมของแอป รวมถึงสี สไตล์ และการตั้งค่าต่างๆ ที่ใช้ใน UI

### widgets/
- **ตำแหน่ง**: `lib/widgets/`
- **คำอธิบาย**: โฟลเดอร์สำหรับเก็บวิดเจ็ตที่ใช้ซ้ำได้ (Reusable Widgets) ที่ใช้ในหลายหน้าจอ
  - **prediction_results.dart**: วิดเจ็ตสำหรับแสดงผลการทำนายหรือผลการวิเคราะห์จากโมเดล AI
  - **xray_viewer.dart**: วิดเจ็ตสำหรับแสดงและดูภาพ X-ray รวมถึงการซูมหรือปรับแต่งภาพ

## สรุป
โครงสร้างนี้ช่วยให้โค้ดของแอปมีระเบียบและง่ายต่อการบำรุงรักษา โดยแบ่งตามหน้าที่รับผิดชอบอย่างชัด เช่น การจัดการสถานะ การแสดงผล และการสื่อสารกับเซิร์ฟเวอร์
